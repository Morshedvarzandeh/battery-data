An equivalent-circuit model: open-circuit voltage against state of charge for a sloped chemistry, scaled to this cell’s published voltages, less the current through its internal resistance, which rises as it gets colder. Heating is adiabatic at 1000 J/(kg·K). This cell’s document did not state: internal resistance 16.33 mΩ. It will not match a cycler. It is here to show which way the numbers move, and how far. Specifications are quoted from manufacturers’ own published documents and remain the property of their publishers. No datasheet is redistributed here: each value is stored with the sentence it was read from, a link to the document and the date it was retrieved.

Where a document did not state the rate, the temperature or the cut‑off a value was measured at, this site says so rather than filling the gap. Nothing on these pages is a manufacturer’s endorsement, and nothing here is a substitute for the current datasheet.
