Documents are registered, not republished. Manufacturer datasheets are almost always copyrighted, so this holds a URL, a SHA-256 of the exact bytes parsed, a retrieval date and a licence — never the document body. source.redistributable governs the exception. Kept this way, a takedown request is a one-source problem instead of a project-ending one.
